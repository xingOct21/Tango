# Tango — 自定义词源的记忆卡片工具

基于间隔重复算法（SRS）的记忆卡片工具，支持云端部署，手机电脑均可使用。

## 项目背景

市面上有很多背单词的 App，但它们有一个共同的局限：**词源是固定的**。

现实中，真正需要记忆的内容往往是这些 App 覆盖不到的——游戏里的俗语、某部小说里的特定用法、某个专业领域的术语、或者某次旅行中遇到的表达。碰到这类情况，人们往往只能退回最原始的方式：写笔记，然后自己背。

作者在玩《逆转裁判》时，遇到了大量日语俗语和母语者惯用表达，这些词绝对不会出现在任何记忆 App 的词库里。为了解决这个问题，作者开发了 Tango：**一个以你自己的笔记为词源的记忆工具**。

## 特色

- **词源完全自定义** — 用一个 Markdown 文件维护你想记的内容，游戏台词、行话、冷僻词，什么都行
- **间隔重复算法** — 记得越熟，复习间隔越长（1天 → 3天 → 7天 → 14天 → 30天），不浪费时间在已掌握的内容上
- **新词/复习分别可调** — 页面内直接设置每天学几个新词、复习几个旧词，不给自己太大压力
- **斩词** — 记得足够牢固的词可以永久退场，不再占用复习时间
- **云端进度同步** — 部署后任何设备打开网页即可使用，进度自动保存
- **零依赖客户端** — 纯网页，不需要安装任何 App

## 部署教程

### 1. Fork 仓库

点击右上角 **Fork**，复制到你自己的 GitHub 账号。

### 2. 准备数据库（Supabase）

1. 注册 [supabase.com](https://supabase.com)，新建一个 Project
2. 进入 **SQL Editor**，执行 `schema.sql` 里的内容（建表）。如果你之前已经部署过旧版本，只需要执行 `schema.sql` 里"增量迁移"那一段
3. 去 **Settings → API**，记下：
   - **Project URL**（如 `https://xxx.supabase.co`）
   - **service_role** 那行的 secret key

### 3. 部署应用（Render）

1. 注册 [render.com](https://render.com)，新建 **Web Service**
2. 连接你 Fork 的 GitHub 仓库
3. 配置如下：
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `gunicorn app:app`
4. 在 **Environment Variables** 里添加：
   - `SUPABASE_URL` = 第 2 步的 Project URL
   - `SUPABASE_KEY` = 第 2 步的 service_role key
5. 点击 Deploy，完成后会得到一个 `https://xxx.onrender.com` 的链接

### 4. 编写你的词表

编辑 `word.md`，格式如下：

```markdown
## 分类名称

| 正面 | 读音（可留空） | 背面 |
|------|----------------|------|
| 食べる | たべる | 吃 |
| 飲む | のむ | 喝 |
```

改完后 push 到 GitHub，Render 会自动重新部署。

## 使用说明

- 打开网页，点击**翻牌**查看答案
- 根据掌握程度点击「不会 / 模糊 / 记住了」
- 点击右上角 ⚙ 可分别设置每天学习的新词数量、复习的旧词数量
- 熟悉度越高（橙点越多），复习间隔越长（最长 30 天）
- 一个词连续记熟到熟悉度满格（5 个橙点）时，会问你要不要把它「斩」掉——斩掉之后这个词永远不会再出现
- 今天的额度用完后，完成界面会同时提供「继续学习」（取消今天的上限，继续学到期词）和「复习」（自由回顾今天学过的词，不影响进度）两个按钮

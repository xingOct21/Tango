## 答辩问答

| 问题 | 答案 | 中文 |
|------|------|------|
|什么是F1分数？请解释一下F1分数。\nWhat is the F1 score? Please explain it.|For a binary classifier, the output is usually a probability score. We compare this score with a threshold, which is usually 0.5. If the probability score is higher than the threshold, we predict the sample as positive. Otherwise, we predict it as negative.\nThen, we compare the predicted label with the real label. This gives us four possible outcomes: true positive (TP), false positive (FP), true negative (TN), and false negative (FN).\nThe F1 score is calculated from precision and recall.\nPrecision = TP / (TP + FP)\nRecall = TP / (TP + FN)\nThe F1 score is the harmonic mean of precision and recall:\nF1 = 2 × (Precision × Recall) / (Precision + Recall)\nIt can also be written as:\nF1 = 2TP / (2TP + FP + FN)|对于二分类器，输出通常是一个概率分数。我们将这个分数与一个阈值（通常是0.5）进行比较：如果概率分数高于阈值，就把该样本预测为正类；否则预测为负类。\n然后，把预测标签与真实标签进行比较，这样会得到四种可能的结果：真阳性(TP)、假阳性(FP)、真阴性(TN)、假阴性(FN)。\nF1分数由精确率（Precision）和召回率（Recall）计算得出。\n精确率 = TP / (TP + FP)\n召回率 = TP / (TP + FN)\nF1分数是精确率和召回率的调和平均数：\nF1 = 2 × (精确率 × 召回率) / (精确率 + 召回率)\n也可以写成：\nF1 = 2TP / (2TP + FP + FN)|
|本节的主要目的是什么？\nWhat is the main purpose of Section 1?|The main purpose is to prove that the ranking changes between two methods can be found exactly.\nWe show that the equality of two binary macro-F1 scores can be reduced to a polynomial equation with degree at most three.\nTherefore, we can find all possible crossing points without using a grid search.|本节的主要目的是证明两个方法之间的排名变化可以被精确地找出来。\n我们证明，两个二分类macro-F1分数相等的条件，可以转化为一个次数最多为三次的多项式方程。\n因此，我们不需要使用网格搜索，就能找到所有可能的交叉点。|
|什么是「成对相等」（pairwise equality）？\nWhat does "pairwise equality" mean?|Pairwise equality means that we compare two methods at a time.\nFor example, we compare Method A and Method B and find the value of \(\lambda\) where their macro-F1 scores are equal.|成对相等指的是每次比较两个方法。\n例如，我们比较方法A和方法B，找出使它们的macro-F1分数相等的 \(\lambda\) 值。|
|为什么要用多项式？\nWhy do you use a polynomial?|The original macro-F1 formula contains fractions, so it is not easy to find all crossing points directly.\nWe transform the equality into a polynomial equation.\nThen we can use exact root-finding methods to find all crossing points.|原始的macro-F1公式包含分数，直接求出所有交叉点并不容易。\n我们把这个相等关系转化为一个多项式方程。\n这样就可以用精确的求根方法找到所有交叉点。|
|为什么多项式的次数最多是三次？\nWhy is the degree at most three?|Along the affine path, the confusion masses are linear functions of \(\lambda\).\nThe error term is also linear, while the denominator has degree at most two.\nWhen we compare two methods, we multiply a linear term by a quadratic term.\nTherefore, the resulting polynomial has degree at most three.|沿着仿射路径，混淆矩阵的各项质量是 \(\lambda\) 的线性函数。\n误差项也是线性的，而分母的次数最多为二次。\n当我们比较两个方法时，相当于用一个线性项乘以一个二次项。\n因此，最终得到的多项式次数最多为三次。|
|\(\lambda\) 的含义是什么？\nWhat is the meaning of \(\lambda\)?|\(\lambda\) controls how the group weights change.\nWhen \(\lambda=0\), we use the empirical group weights.\nWhen \(\lambda=1\), we use the reference group weights.\nValues between zero and one represent the transition between these two compositions.|\(\lambda\) 控制着组权重如何变化。\n当 \(\lambda=0\) 时，使用的是经验组权重。\n当 \(\lambda=1\) 时，使用的是参考组权重。\n介于0和1之间的取值，代表这两种组成之间的过渡状态。|
|什么是「交叉点」（crossing point）？\nWhat is a "crossing point"?|A crossing point is a value of \(\lambda\) where two methods have exactly the same macro-F1 score.\nAt this point, their ranking can potentially change.|交叉点是指使两个方法的macro-F1分数完全相等的 \(\lambda\) 值。\n在这个点上，它们的排名有可能发生变化。|
|是不是每个交叉点都意味着排名反转？\nDoes every crossing point mean a ranking reversal?|No. A crossing point does not always mean a ranking reversal.\nIf the two curves only touch and then move apart, the ranking does not change.\nWe call this a tangential tie.\nIf the curves cross each other, it is a ranking reversal.|不是。交叉点并不总是意味着排名反转。\n如果两条曲线只是相切然后又分开，排名并不会改变。\n我们把这种情况称为「相切平局」（tangential tie）。\n如果两条曲线真正互相穿过，那才是排名反转。|
|什么是重数（multiplicity），它为什么重要？\nWhat is multiplicity, and why is it important?|Multiplicity tells us how many times a root is repeated.\nAn odd multiplicity usually means that the sign changes around the root, so it indicates a ranking reversal.\nAn even multiplicity means that the sign does not change, so it indicates a tangential tie.|重数表示一个根重复出现的次数。\n奇数重数通常意味着该根附近符号发生了变化，因此代表排名反转。\n偶数重数意味着符号没有变化，因此代表相切平局。|
|什么是有理隔离区间（rational isolating interval）？\nWhat is a rational isolating interval?|A rational isolating interval is a small interval that contains exactly one real root.\nInstead of giving only an approximate value, we give an interval that guarantees where the root is located.|有理隔离区间是一个恰好只包含一个实根的小区间。\n我们给出的不是一个近似值，而是一个能保证根所在位置的区间。|
|为什么不使用网格搜索？\nWhy don't you use grid search?|Grid search can miss a crossing point between two grid points.\nIt also gives only an approximate location of the crossing.\nOur method finds the roots of the polynomial directly, so it can identify all real roots on the specified path.|网格搜索可能会漏掉两个网格点之间的交叉点。\n而且它给出的交叉位置也只是近似值。\n我们的方法直接求多项式的根，因此能够找出指定路径上所有的实根。|
|什么是「完整证书」（complete certificate）？\nWhat does "complete certificate" mean?|It means that for the fixed prediction table and the specified path, we can identify all pairwise crossing points and ranking intervals.\nWe do not need to choose a grid resolution.|这意味着，对于固定的预测表和指定的路径，我们能够找出所有成对的交叉点和排名区间。\n我们不需要选择网格分辨率。|
|什么是「依赖于人工产物」（artifact-conditional）？\nWhat does "artifact-conditional" mean?|It means that the certificate is exact for the fixed prediction artifact used in the evaluation.\nWe do not claim that the result is universally true for all datasets or all future predictions.|这意味着该证书对于评估中使用的固定预测结果是精确成立的。\n我们并不宣称这个结论对所有数据集或未来的所有预测都普遍成立。|
|为什么有理数端点很重要？\nWhy are rational endpoints important?|The group weights at the two endpoints are rational numbers because they are based on counts.\nTherefore, we can keep the calculations as exact fractions instead of floating-point numbers.\nThis allows us to obtain exact polynomial coefficients and rigorous root intervals.|两个端点上的组权重都是有理数，因为它们是基于计数得到的。\n因此，我们可以把计算过程保持为精确的分数，而不是浮点数。\n这使我们能够得到精确的多项式系数和严格的根区间。|
|「三次是紧的」（degree three is tight）是什么意思？\nWhat does "degree three is tight" mean?|It means that three is not only an upper bound.\nWe can construct a valid example where the resulting polynomial actually has degree three.\nTherefore, the bound cannot be reduced to two in general.|这意味着三次不仅仅是一个上界。\n我们可以构造出一个有效的例子，使得最终的多项式确实达到三次。\n因此，这个界限在一般情况下不能降低到二次。|
|第一节的最终结论是什么？\nWhat is the final result of Section 1?|The main conclusion is that, for a fixed prediction table and a specified affine weighting path, the equality between two binary macro-F1 scores can be reduced to a polynomial equation of degree at most three. Therefore, we can find all crossing points exactly and determine whether each crossing is a real ranking reversal or only a tangential tie.|主要结论是：对于固定的预测表和指定的仿射加权路径，两个二分类macro-F1分数相等的条件可以转化为一个次数最多为三次的多项式方程。因此，我们能够精确地找出所有交叉点，并判断每个交叉点究竟是真正的排名反转，还是仅仅是相切平局。|
|你的 ViViT fine-tuning 中主要的超参数有哪些？\nWhat are the main hyperparameters in your ViViT fine-tuning?|The main hyperparameters are the number of frozen layers, learning rate, dropout, weight decay, label smoothing, scheduler, batch size, and random seed.|主要的超参数包括：冻结层数、学习率、Dropout、Weight Decay、Label Smoothing、Scheduler、Batch Size 和随机种子。|
|学习率的作用是什么？\nWhat is the role of the learning rate?|The learning rate controls how much the model parameters are updated in each step.|学习率控制模型参数在每一步更新时的变化幅度。|
|Dropout 的作用是什么？\nWhat is the role of dropout?|Dropout randomly disables some neurons during training to reduce overfitting.|Dropout 在训练时随机关闭一部分神经元，以减少过拟合。|
|什么是 Weight Decay？\nWhat is weight decay?|Weight decay penalizes large model weights and helps reduce overfitting.|Weight Decay 对过大的模型权重施加惩罚，有助于减少过拟合。|
|什么是 Label Smoothing？\nWhat is label smoothing?|Label smoothing prevents the model from becoming too confident about the training labels.|Label Smoothing 防止模型对训练标签过度自信。|
|什么是 Scheduler？\nWhat is a scheduler?|A scheduler changes the learning rate during training. In our experiment, we used a cosine scheduler to gradually reduce the learning rate.|Scheduler 在训练过程中调整学习率。在我们的实验中，使用了 Cosine Scheduler 让学习率逐渐降低。|
|为什么要冻结大部分层？\nWhy did you freeze most of the layers?|Because our training dataset was very small. Freezing most layers reduced overfitting while still allowing the last layers to adapt to our task.|因为训练数据集非常小。冻结大部分层可以减少过拟合，同时仍允许最后几层适配我们的任务。|
|Section 2 的主要目的是什么？\nWhat is the main purpose of Section 2?|The main purpose is to define a reliable and reproducible audit procedure.\nWe first check the prediction artifact, then keep the model decisions fixed, change only the group weights, and finally calculate the ranking changes.|主要目的是定义一个可靠且可复现的审计流程。\n我们首先检查预测结果文件，然后保持模型的判断不变，只改变组权重，最后计算排名的变化。|
|为什么在分析之前需要做完整性检查？\nWhy do you need integrity checks before the analysis?|We need to make sure that the input data is correct before calculating the results.\nWe check the file structure, file IDs, labels, groups, folds, scores, and fusion results.\nIf any check fails, the analysis stops.|我们需要在计算结果之前，确保输入数据是正确的。\n我们检查文件结构、文件ID、标签、组别、折数、分数和融合结果。\n如果任何一项检查失败，分析就会停止。|
|什么是结构检查（schema check）？\nWhat is a schema check?|A schema check verifies that the prediction table has the expected structure.\nFor example, the required columns, column names, and data types must be correct.|结构检查用来验证预测表是否具有预期的结构。\n例如，必须有正确的列、正确的列名和正确的数据类型。|
|为什么要用文件ID来对齐数据？\nWhy do you use file IDs to align the data?|File IDs make sure that the prediction, label, group, and fold belong to the same clip.\nThis avoids incorrect alignment caused by relying only on the row order.|文件ID可以确保预测、标签、组别和折数都属于同一个片段。\n这样可以避免只依赖行顺序而造成的错误对齐。|
|"文件ID双射"（file-ID bijection）是什么意思？\nWhat does "file-ID bijection" mean?|It means that each file ID has exactly one corresponding prediction, and each prediction can be matched to exactly one file ID.\nIn other words, the mapping is one-to-one.|这表示每个文件ID恰好对应一个预测结果，每个预测结果也恰好能匹配一个文件ID。\n换句话说，这是一个一一对应的关系。|
|"每个判断都是固定的"是什么意思？\nWhat does "every decision is fixed" mean?|It means that we do not change the model predictions during the audit.\nFor a continuous score, we use the fixed threshold of \(0.5\) to obtain the binary decision.\nOnly the group weights are changed.|这表示在审计过程中，我们不会改变模型的预测结果。\n对于一个连续分数，我们使用固定的阈值 \(0.5\) 来得到二分类判断。\n只有组权重会发生变化。|
|为什么在路径中不改变阈值？\nWhy don't you change the threshold along the path?|The purpose of the audit is to study the effect of group reweighting.\nIf we also changed the threshold, the model decisions would change at the same time.\nThen we could not clearly separate the effect of weighting from the effect of threshold selection.|审计的目的是研究组重新加权带来的影响。\n如果同时改变阈值，模型的判断也会随之改变。\n这样我们就无法清楚地区分加权的影响和阈值选择的影响。|
|你是如何改变组权重的？\nHow do you change the group weights?|We use the affine path\n\n\[\nq_g(\lambda)=(1-\lambda)p_g+\lambda r_g,\n\]\n\nwhere \(p_g\) is the empirical group weight and \(r_g\) is the declared reference weight.\n\nAt \(\lambda=0\), we use the empirical composition.\nAt \(\lambda=1\), we use the reference composition.|我们使用如下的仿射路径：\n\n\[\nq_g(\lambda)=(1-\lambda)p_g+\lambda r_g,\n\]\n\n其中 \(p_g\) 是经验组权重，\(r_g\) 是设定的参考权重。\n\n当 \(\lambda=0\) 时，使用的是经验组成。\n当 \(\lambda=1\) 时，使用的是参考组成。|
|改变组权重之后，最终的macro-F1是如何计算的？\nHow do you calculate the final macro-F1 after changing the group weights?|First, we calculate the confusion proportions inside each group.\nThen we combine the groups using their new weights \(q_g(\lambda)\).\nThis gives the pooled \(TP\), \(FP\), \(FN\), and \(TN\).\nFinally, we calculate binary macro-F1 from these pooled confusion masses.|首先，我们计算每个组内部的混淆比例。\n然后用新的权重 \(q_g(\lambda)\) 把各组合并起来。\n这样就得到了汇总后的 \(TP\)、\(FP\)、\(FN\) 和 \(TN\)。\n最后，我们用这些汇总的混淆质量计算二分类macro-F1。|
|为什么要成对比较各个方法？\nWhy do you compare methods pairwise?|We compare two methods at a time because a ranking change happens when the scores of two methods become equal and then change order.\nWith \(K\) methods, the number of pairs is\n\n\[\n\frac{K(K-1)}{2}.\n\]\n\nFor 10 methods, there are\n\n\[\n\frac{10\times9}{2}=45\n\]\n\npairs.|我们每次比较两个方法，因为当两个方法的分数相等并且顺序发生变化时，排名就会改变。\n如果有 \(K\) 个方法，配对的数量是\n\n\[\n\frac{K(K-1)}{2}\n\]\n\n对于10个方法来说，一共有\n\n\[\n\frac{10\times9}{2}=45\n\]\n\n对。|
|找到交叉点之后，你会做什么？\nWhat do you do after finding a crossing point?|We check the root multiplicity and the signs on both sides of the root.\nIf the sign changes, it is a ranking reversal.\nIf the sign does not change, it is a tangential tie.|我们检查根的重数，以及根两侧的符号。\n如果符号发生变化，就是排名反转。\n如果符号没有变化，就是相切平局。|
|什么是排名区间（ranking interval）？\nWhat is a ranking interval?|A ranking interval is a range of \(\lambda\) values where the ranking stays unchanged.\nWe find all crossing points first and use them to divide \([0,1]\) into intervals.|排名区间是指在这个范围内 \(\lambda\) 的取值，排名保持不变。\n我们先找出所有的交叉点，再用它们把 \([0,1]\) 划分成若干区间。|
|什么是最优方法包络（top-method envelope）？\nWhat is the top-method envelope?|The top-method envelope shows which method is ranked first at each part of the path.\nFor example, in our case, Fusion is first before the crossing at about\n\n\[\n\lambda^\star\approx0.2034,\n\]\n\nand Text SVM becomes first after that point.|最优方法包络显示的是在路径的每一部分，哪个方法排名第一。\n例如在我们的例子中，在交叉点\n\n\[\n\lambda^\star\approx0.2034\n\]\n\n之前，Fusion排名第一；在这之后，Text SVM变成排名第一。|
|为什么这个流程是可复现的？\nWhy is the procedure reproducible?|The input artifact, file alignment, threshold, weighting path, and calculation rules are all fixed and recorded.\nTherefore, another researcher can use the same inputs and procedure to obtain the same result.|输入文件、文件对齐方式、阈值、加权路径和计算规则都是固定并且被记录下来的。\n因此，其他研究者可以使用相同的输入和流程，得到相同的结果。|
|RLTD 中有多少 clips、groups 和 folds？\nHow many clips, groups, and folds are there in RLTD?|RLTD has 121 clips. 61 of them are Deceptive and 60 are Truthful.\nFrom the metadata in the README, we get 32 exact-match groups, and we use a fixed 5-fold assignment.\nNote that these 32 groups are not 32 speakers.|RLTD 有 121 条 clips，其中 61 条是 Deceptive，60 条是 Truthful。\n根据 README 的 metadata，我们得到 32 个 exact-match groups，并使用固定的 5-fold assignment。\n注意：这 32 个 groups 不是 32 个 speakers。|
|这 32 个 groups 是怎么得到的？\nHow did you get these 32 groups?|We use the `Role / trial name` field in the README and match it exactly, with case sensitivity.\nIf the field contains a `/`, we take the trial name on the right side of the `/`.\nWe do not do alias resolution, person linking, or case inference.\nSo these groups should be called parser-derived groups.|我们根据 README 中的 `Role / trial name` 字段进行 exact、case-sensitive matching。\n如果字段中有 `/`，我们使用 `/` 右边的 trial name。\n我们没有做 alias resolution、person linking 或 case inference。\n因此，这些 groups 应该称为 parser-derived groups（由解析得到的组）。|
|为什么不能重新运行一个新的 cross-validation splitter？\nWhy can't you just run a new cross-validation splitter?|We use the fixed `fold_assignment.csv` directly.\nSome groups have the same size. |为什么 G03 特别重要？\nWhy is G03 so important?|G03 is the largest group. |什么是 pooled OOF difference？\nWhat is the pooled OOF difference?|OOF means out-of-fold prediction.\nPooled means that we put all OOF predictions together and calculate one overall macro-F1.\nIn our result, the pooled difference between mean fusion and Text SVM is\n\n\[\n+0.021565.\n\]\n\nSo under empirical clip weighting, Fusion is ranked higher.|OOF 表示 out-of-fold prediction（折外预测）。\nPooled 表示把所有 OOF predictions 放在一起计算一个总体 macro-F1。\n我们的结果中，mean fusion 和 Text SVM 的 pooled difference 是\n\n\[\n+0.021565\n\]\n\n因此，在 empirical clip weighting 下，Fusion 排名更高。|

|什么是 leave-one-group-out？\nWhat is leave-one-group-out?|We have 32 groups in total.\nEach time we remove one group and then calculate the difference between Fusion and Text SVM again.\nSo we do 32 recalculations.|我们一共有 32 个 groups。每次删除其中一个 group，然后重新计算 Fusion 和 Text SVM 的差值，共进行 32 次 recalculation。|
